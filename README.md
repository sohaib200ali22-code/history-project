# 𓋹 الحياة الاقتصادية في مصر القديمة | رحلة تفاعلية

موقع ويب تفاعلي يستعرض جوانب الحياة الاقتصادية في مصر القديمة بأسلوب بصري حديث وتجربة مستخدم سلسة.

🔗 **رابط معاينة الموقع (Live Demo):**  
<a href="https://sohaib200ali22-code.github.io/history-project/">اضغط هنا لزيارة الموقع</a>

---

## ✨ مميزات المشروع
- **تصميم مستوحى من الحضارة المصرية:** ألوان ذهبية وداكنة تعكس هوية مصر القديمة.
- **الوضع الليلي والنهاري (Dark / Light Mode):** إمكانية التبديل بسهولة لراحة العين.
- **خرائط تفاعلية:** عرض المواقع التاريخية والتجارية باستخدام مكتبة Leaflet.js.
- **تجربة متجاوبة (Responsive):** يعمل بسلاسة على الكمبيوتر والموبايل.

---

## 🛠️ التقنيات المستخدمة
- **HTML5 & CSS3** (Custom CSS Variables)
- **JavaScript**
- **Leaflet.js** (للخرائط التفاعلية)
- **Font Awesome & Google Fonts** (خطوط Cairo و Amiri)
